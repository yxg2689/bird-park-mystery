# 🕵️ 鳥園奇案事件簿

> 教育部青年發展署大專生公部門見習計畫
> 國立自然科學博物館 鳳凰谷鳥園生態園區見習 專題

一款搭配實體園區使用的**網頁解謎遊戲**。遊客在鳥園中自由探索，於各展區找到關卡入口後進入事件，透過觀察展示板、標本與園區設施回答問題、蒐集線索，最後推理出幕後的兇手。

以 PHP 撰寫，不需要資料庫，放在任何支援 PHP 的主機上就能執行，介面以手機瀏覽為主要情境設計。

---

## 專案狀態

🧪 **測試階段**：尚未正式在園區上線。

遊戲原本的構想是在園區各展區設置 **QR Code**，遊客掃描後直接進入對應關卡。為了方便設計與展示（demo），目前先以**輸入關卡密鑰**的方式代替掃描 QR Code。

---

## 遊戲流程

```
首頁（劇情、遊戲提示、園區地圖）
 │
 ├─ 輸入某一關的密鑰 ──▶ 直接進入該事件 ──▶ 回答問題
 │   （未來改為掃描 QR Code）                ├─ 答對：獲得線索
 │                                          └─ 答錯：獲得提示，可再試一次
 │
 └─ 回答終極問題「誰是兇手？」
         ├─ 答對 ──▶ 揭開最後真相＋領獎說明
         └─ 答錯 ──▶ 回到首頁繼續調查
```

- 四個事件各有獨立的入口，**沒有固定順序**，遊客走到哪一區就玩哪一關。
- 已解鎖的事件會顯示在首頁的「調查進度」，可以點回去重看。
- 不需要解完所有事件，就可以隨時挑戰終極問題。

## 專案結構

```

├── index.php          首頁：劇情、遊戲提示、地圖、輸入密鑰、調查進度、終極問題
```

## 執行環境

- PHP 7.0 以上
- 建議開啟 `mbstring` 擴充（用來把全形英數字轉成半形；沒開也能執行，只是全形輸入不會被自動轉換）
- 不需要資料庫

## 本機執行

**方法一：XAMPP**

1. 把 `BirdGame` 資料夾放進 XAMPP 的 `htdocs`。
2. 在 XAMPP Control Panel 啟動 Apache。
3. 瀏覽器打開 `http://localhost/BirdGame/index.php`。

**方法二：PHP 內建伺服器**

```bash
cd BirdGame
php -S localhost:8000
```

瀏覽器打開 `http://localhost:8000`。

**用手機測試**

手機和電腦連同一個 Wi-Fi，把網址中的 `localhost` 換成電腦的區網 IP（例如 `http://192.168.1.23/BirdGame/index.php`）。如果用 `php -S`，要改成 `php -S 0.0.0.0:8000` 手機才連得到。

> GitHub 只存放程式碼，**不會執行 PHP**，所以無法用 GitHub Pages 直接開來玩，需要部署到支援 PHP 的主機。

## 修改遊戲內容

| 想改的東西 | 檔案 | 位置 |
|---|---|---|
| 各關密鑰 | `index.php` | `$stage_keys` |
| 首頁顯示的關卡名稱 | `index.php` | `$stage_names` |
| 首頁劇情、遊戲提示 | `index.php` | `<div class="story">`、`<div class="tips">` |
| 各關劇情與題目 | `stage.php` | `$stages` |
| 各關正確答案 | `check_answer.php` | `$stages` |
| 答對線索、答錯提示 | `check_answer.php` | `$success_hints`、`$fail_hints` |
| 答錯提示圖片 | `check_answer.php` | `$fail_images` |
| 終極問題答案 | `final_answer.php` | `$correct_answers` |
| 結局劇情、領獎說明 | `success.php` | `<div class="ending-text">`、`<div class="prize">` |

**密鑰格式**：左邊是玩家要輸入的字串，右邊是關卡編號。

```php
$stage_keys = [
    'FEATHER' => 1,
    'CRANE'   => 2,
    // ...
];
```

**提示圖片**：答錯時會先顯示提示文字，再依序顯示圖片。圖片放在 `image/`，路徑寫在 `$fail_images`，檔名大小寫與副檔名須和實際檔案一致。

```php
$fail_images = [
    4 => [
        'image/caneat.jpg',
        'image/cannoteat.jpg',
    ],
];
```

**答案判斷規則**：比對時會自動處理以下情況，寫答案時不用列出各種寫法。

- 不分大小寫（`h` 和 `H` 都算對）
- 全形轉半形（`Ｈ`、`１` 也算對）
- 忽略所有空白（`飼育員 Herbert` 和 `飼育員Herbert` 都算對）

終極問題的答案請**全部寫小寫、不含空白**，例如 `"飼育員herbert"`。

> `stage.php` 裡也有一份 `answer` / `answers`，但實際判斷對錯只看 `check_answer.php`，改答案時以後者為準。

## 進度紀錄

遊戲進度以 PHP Session 記錄，**不需要登入**。

- 同一台裝置、同一個瀏覽器會保留進度；換瀏覽器、換裝置或使用無痕模式則從頭開始。
- 遊戲設計為園區遊客一次性遊玩，因此不提供「重新開始」功能。
- 防作弊：直接在網址輸入 `stage.php?stage=3` 或 `success.php` 會被導回首頁，必須先解鎖關卡或答對終極問題。
- 伺服器預設閒置約 24 分鐘後可能清除 Session。若遊客在園區走動時間較長，可在每個檔案的 `session_start()` 前加入以下設定，延長到 3 小時：

  ```php
  ini_set('session.gc_maxlifetime', 10800);
  session_set_cookie_params(10800);
  ```

## 未來構想

以下是若遊戲正式導入園區時可以延伸的方向：

- **QR Code 進入關卡**：在各展區設置 QR Code，遊客掃描後直接進入對應關卡，取代手動輸入密鑰。
- **資料庫管理題目**：題目數量增加後，改用資料庫管理關卡劇情、題目、答案與提示，不必再修改程式碼。
- **隨機出題**：同一展區準備多道題目，每位遊客遇到的題目不同，關卡不再固定。
